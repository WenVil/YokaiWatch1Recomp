# Building YokaiWatch1Recomp on Windows

`YokaiWatch1Recomp` ([WenVil/YokaiWatch1Recomp](https://github.com/WenVil/YokaiWatch1Recomp)) targets **Windows 10 / 11 (x86-64)** using **MSYS2 UCRT64** (`clang` + `lld` + **OpenGL 4.5** + **SDL3** + pure **LGPLv2.1+ FFmpeg**), including the pure OpenGL state-machine Yo-kai Watch search lens fix (packed `D24S8` stencil clear + stencil-write alpha-test suppression across all revisions) and `beta1`-compatible `GAMELIB_ID`, producing `YokaiWatch1Recomp.exe` and a self-contained zero-copyright distributable archive (e.g., `YokaiWatch1Recomp-v1.0.0-beta2-windows.zip`).

---

## 1. Prerequisites

### MSYS2 UCRT64 Toolchain

Run [tools/setup_windows.ps1](../tools/setup_windows.ps1) or install the packages manually in an MSYS2 UCRT64 shell:

```bash
pacman -S --needed --noconfirm \
  make \
  mingw-w64-ucrt-x86_64-clang \
  mingw-w64-ucrt-x86_64-lld \
  mingw-w64-ucrt-x86_64-sdl3 \
  mingw-w64-ucrt-x86_64-pkgconf \
  mingw-w64-ucrt-x86_64-gdb \
  mingw-w64-ucrt-x86_64-nasm
```

> [!IMPORTANT]
> **Pure LGPLv2.1+ FFmpeg**: MSYS2's default `mingw-w64-ucrt-x86_64-ffmpeg` package is compiled with `--enable-gpl` and depends on `libx264` / `libx265`. Release builds MUST use `DEPS=<lgpl-prefix>` generated by [tools/build_deps_windows.sh](../tools/build_deps_windows.sh) so zero GPL FFmpeg codecs are linked or shipped.

### CPython 3.12 (for Freezing `yw1gen.exe`)

Install official Windows CPython 3.12 (`64-bit`) and prepare:
- `tools/venv/` with `capstone==5.0.9`, `unicorn==2.1.4`, `lz4==4.4.5`
- `pyinstaller==6.22.3` (either in `tools/venv` or system CPython 3.12; [tools/yw1gen.spec](../tools/yw1gen.spec) pulls dependencies from `tools/venv/Lib/site-packages`)

---

## 2. Building Pure LGPL Dependencies & Slimmed Zig

From MSYS2 UCRT64:

```bash
# 1. Build pure LGPLv2.1+ FFmpeg (and verify SDL3 libs under DEPS)
bash tools/build_deps_windows.sh

# 2. Fetch Zig 0.17.0 and slim its runtime cache (precompiles C runtime for 0 rebuilds on end-user machines)
bash tools/fetch_zig.sh
```

To build only the slimmed Zig directory cleanly:

```bash
bash tools/zig_slim.sh -O1 -fno-strict-aliasing -Wno-return-type -Wno-unused-label -fvisibility=hidden -D_FILE_OFFSET_BITS=64 -march=x86-64-v3
```

---

## 3. Freezing `yw1gen.exe`

Freeze `tools/gen.py` and `tools/game_addresses.py` into a standalone helper folder and strip Control Flow Guard (`pe_no_cfg.py`) for Unicorn compatibility on Windows:

```powershell
python -m PyInstaller --noconfirm --clean tools/yw1gen.spec
python tools/pe_no_cfg.py build/helper/yw1gen/yw1gen.exe
```

Or via Makefile:

```bash
make GEN_PY=/path/to/python.exe gen-helper
```

---

## 4. Building `YokaiWatch1Recomp.exe` and `dist` Archive

```bash
make -j16 RELEASE=1 GEN=NONE DEPS=/path/to/lgpl-deps dist
```

Release hygiene checks enforced by `make dist`:
- Zero compiled Switch guest functions (`llvm-nm build/YokaiWatch1Recomp.exe | grep ' f_70'` must be empty).
- Zero GPL FFmpeg / encoder DLLs (`libx264`, `libx265`, `libxvidcore`, `postproc`) or `vulkan` / `shaderc` DLLs.
- Only minimal non-system DLLs are staged (`SDL3.dll`, `avcodec-63.dll`, `avformat-63.dll`, `avutil-61.dll`, `swscale-10.dll`, `libiconv-2.dll`, `libgcc_s_seh-1.dll`, `libwinpthread-1.dll`, `libstdc++-6.dll`).
- Output folder and release archive: `YokaiWatch1Recomp-v1.0.0-beta2-windows/` and `YokaiWatch1Recomp-v1.0.0-beta2-windows.zip` (preserves `beta1` `GAMELIB_ID` compatibility so existing `yw1game_<build16>.dll` modules load without recompilation).

---

## 5. Runtime File Layout

Next to `YokaiWatch1Recomp.exe` (or inside `RECOMPLAUNCHER_DATA` / `LARECOMP_DATA_ROOT`):
- `yw1game_<build16>.dll` — compiled 2-module native game library (`main` + `sdk`)
- `.gamebuild/` — generated C sources, Zig build cache, and `gamelib_entry.receipt`
- `yokaiwatch1.ini` — persistent settings & hotkeys (migrates `larecomp.ini` automatically if present)
- `save/` and `save_backups/` — Switch save data and automatic rolling backups
- `mods/<mod_name>/romfs/` — optional LayeredFS mod overrides
- `yokaiwatch1recomp.log` and rotated `yokaiwatch1recomp-backup-*.log` logs (`RELEASE=1`)
